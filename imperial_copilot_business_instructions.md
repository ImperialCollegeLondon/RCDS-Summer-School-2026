# Instructions for Activating GitHub Copilot Business License for Imperial Staff and Postgraduate Students

Imperial ICT provide GitHub Copilot business paid subscriptions to Imperial staff and postgraduate students who are involved in research. If you use GitHub Copilot to assist you with programming tasks, these plans provide a high quota which is suitable for regular use (just make sure not use the most expensive models available unless necessary). To get access to this plan you will need to:

* Make a [GitHub account](https://github.com/),
* Join the [Imperial GitHub organisation](https://imperialcollegelondon.github.io/docs/gain_access) by clicking [here](https://github.com/orgs/ImperialCollegeLondon/sso),
* Request a licence by visiting [this repository](https://github.com/ImperialCollegeLondon/github-resources#how-to-request-a-github-copilot-for-business-license) and creating an issue on that repository.

You should do this before the summer school starts - it is advised to start it at least ten days before in case there are delays in the process.
